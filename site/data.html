Datasets

Three Regionals, 3,004 teams

Masters division at Frankfurt (Sep 26–27), Louisville (Oct 10–11) and Nice (Oct 17–18), 2026, Pokémon Champions Reg M-C. Every team's six sets, final placing, Day 1 record and every pairing. Player names and team-sheet links are removed. A team is identified only by event and place.

Harness

Rebuild everything

Four scripts in meta/. Requires Node 22.18+, the pinned Showdown build from npm run prepare:data, and uv for the Python step.

npm ci && npm run prepare:data          # pinned Showdown Champions engine
node meta/events.mjs                     # fetch, normalise, anonymise, tokenise
uv run --with numpy --with scikit-learn \
  python -I meta/plans.py                # plans, probe, loops, map
node meta/cases.mjs                      # every report number
node meta/mechanics.cjs                  # engine checks

events.mjs

Loads each event, keeps the Masters division, drops names, resolves Mega forms and abilities in the engine, and writes the team tokens. Pass other event slugs to add events.

plans.py

Dictionary learning, the pairwise probe, loops checked against raw records, and a t-SNE map. Deterministic seeds.

cases.mjs

Filters and counts behind each report claim, written out so any of them can be argued with.

mechanics.cjs

Scripted doubles turns in the engine: terrain, Electric Seed, Unburden speed, Sleep Powder over 40 seeds, Lightning Rod.
