GIMMIKWATCH · HARNESS

How the agent thinks

An agent answers a team question by running checks, not by recalling. It queries a graph of game mechanics, runs the real battle engine and damage calculator, reads what the field actually played, and writes what it finds into a small just-in-time graph. That graph is the agent's working memory: plans that take several turns become paths through it.

Meta harness

Turns open team sheets into plans, a matchup matrix and per-event shares. What was played, and how it did.

Engine and calculator

Answer what the agent can't eyeball: does terrain pop the Seed, does Sleep Powder land, does +2 Draco one-shot. Every answer is re-runnable.

Graph over MCP

The agent reads and writes FalkorDB through its MCP server, so the memory outlives the chat.

What the agent can see

Three layers

MECHANICS   what can happen      species · moves · abilities · items · type chart     engine
    │
TEMPORAL    what was played      events → teams → plans → matchups → shares           meta harness
    │
IDEA        what we're testing   built per question · revised by adding, never erased  agent

Mechanics say what's possible. The temporal layer says what the field did and when, which is what "why now" needs. The idea layer holds the current theory: claims, the check behind each one, and what would break it.

                                                                ▼

Louisville ──FIELD SHIFT──▶ Nice     Scarf Garchomp 13 → 27%   Snarl 18 → 47%

Each edge carries its evidence: SETS and TRIGGERS come from engine runs, the speeds from battle-form stats, the field shift from the team sheets. Swap Raichu X for Raichu Y and the SETS edge disappears, and so does everything downstream of it. That is the 15-2 and the 0-8, read off the graph.

Long-horizon planning

Plans are paths

A win that takes several turns (Mega Evolve, terrain pops the Seed, Swords Dance, sweep) isn't one edge. It's a path. Store each step as an edge with its condition and the check that proved it, and a multi-turn plan becomes a bounded path query:

MATCH p = (start)-[:ENABLES*2..5]->(goal {kind: 'win'})
RETURN p

The agent searches routes instead of re-deriving them, and every route arrives with its receipts. In an exploratory run, a query like this over a stat-effect graph returned about 4,400 setup chains in about 110 ms. Because the graph persists, the next session continues the theory instead of starting over.

Datasets

Three Regionals, 3,004 teams

Masters division at Frankfurt (Sep 26–27), Louisville (Oct 10–11) and Nice (Oct 17–18), 2026, Pokémon Champions Reg M-C. Player names and team-sheet links are removed. A team is identified only by event and place.
