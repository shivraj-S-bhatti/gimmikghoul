# Visual assets

`gimmighoul-scientist-v2.png` is an AI-generated fan mascot, created with the built-in image generation tool on 2026-10-18. The user directed the lab coat and clipboard, then corrected the anatomy to coin spectacles and sharply bent antennae. References supplied by the user informed the character's anatomy and the pixel-art scientist style. Reference photographs are not redistributed in this repo.

Pokémon characters and names belong to their respective owners. This independent project does not claim ownership of the character or affiliation with Pokémon. The mascot is used in the README and is available as a repository branding asset; GitHub does not assign a separate profile avatar to each repository.

Sprites in `data/sprites/` retain their source URLs and hashes in `manifest.json`. Exact forms must not silently fall back to a different form. The editable SVG diagrams embed selected sprites for portability and link conceptual records rather than claiming observed results.

[Generation prompts](PROMPTS.md) document the mascot workflow. The first anatomically incorrect draft is excluded from the public repository.
